## 🩸 Clive Barker's Hellraiser: Revival — Indonesian Localization v1.0 (Full Release)

Rilis perdana **v1.0 (Tamat 100%)** mod lokalisasi Bahasa Indonesia untuk game **Clive Barker's Hellraiser: Revival** (PC Steam / Steam Deck).

---

### 🌟 Ringkasan Pembaruan & Fitur Utama v1.0
- **100% Dialog Cerita Utama (Prologue s/d Epilogue)**: Menghidupkan seluruh dinamika emosi keputusasaan Aidan Lynch, teror sadomasokistik kultus Marlowe & Bruno Keller, hingga kebijaksanaan dingin sang Hell Priest (Pinhead).
- **Voices of the Damned (Ambient & Combat Barks)**: Seluruh 2.593 celetukan tempur musuh, seruan ritual para kultis, dan reaksi histeris terhadap jeratan rantai neraka (*Hellchains*) diterjemahkan dengan laras bahasa yang luwes dan hidup.
- **Lore Notes, Kaset & Death Hints Tuntas**: 153 lembar dokumen okultis rahasia (Bab 1 s/d 6), 22 rekaman audio kaset, 169 tips layar kematian (*DeathHintText*), dan inskripsi teka-teki dinding.
- **Sinkronisasi Fonetik Kata Terbata-bata (Stuttering Sync)**: Huruf/suku kata gagap diselaraskan secara fonetis dengan kata target Bahasa Indonesia (*W-wait* ➔ *T-tunggu*, *N-no* ➔ *J-jangan*, *W-we* ➔ *K-kami*).
- **English UI & Weapon Policy**: Menu utama, opsi pengaturan, dan nama senjata tetap original Bahasa Inggris agar pemain tetap familiar dengan panduan komunitas internasional.
- **Direct Base Container Injection (pakchunk0-Windows.pak)**: Menggunakan teknologi repak V11 dengan preservasi *PathHashSeed* `0x0BF2F7AD` dan kompresi *Oodle*. 100% terbaca otomatis tanpa modloader pihak ketiga dan zero background overhead.

### 📥 Petunjuk Pemasangan (Sangat Mudah - Drop-In)
1. Unduh file aset **`Hellraiser_Revival_Indonesian_Translation_v1.0.zip`** di bawah.
2. Buka folder instalasi game **Clive Barker's Hellraiser: Revival** di Steam:
   - Steam Library ➔ Klik kanan *Clive Barker's Hellraiser: Revival* ➔ *Manage* ➔ *Browse local files*.
3. *(Disarankan)* Masuk ke folder `Hellraiser/Content/Paks/` dan buat salinan cadangan file `pakchunk0-Windows.pak` menjadi `pakchunk0-Windows.pak.orig.bak`.
4. Ekstrak folder **`Hellraiser`** dari dalam folder `TIMPA_KE_FOLDER_GAME` ke folder instalasi game kamu (pilih *Replace / Timpa*).
5. Jalankan game dan nikmati permainannya!
